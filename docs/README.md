# docs

kids-drillの設計ドキュメント置き場。決定事項ができるたびにここを更新していく。

- [architecture.md](./architecture.md) — 技術スタック・インフラ・認証まわりの設計
- [game-design.md](./game-design.md) — ドリルのゲーム性・出題ロジック・キャラクター育成などの設計（検討中）

## 方針

- ここは公開リポジトリの一部として公開される想定。設計内容そのものに秘匿性はないので気にせず書く。
- ただし以下は書かない:
  - 実在の子どもの本名・通っている学校名など個人を特定できる情報（仮称・ダミー名を使う）
  - APIキー・DB接続文字列・認証シークレットなどの秘密情報（`.env.local`に置き`.gitignore`で除外）
